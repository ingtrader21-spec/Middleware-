# QA Guide

QA reviewers can search completed calls within their authorized tenant scope and score Greeting, Verification, Product Knowledge, Compliance, Call Control, Empathy and Closing from zero to five.

All categories are required. The server computes the percentage. A submitted review is immutable and cannot be deleted. If coaching is required, add a useful comment and create the coaching task; the call's assigned agent must acknowledge it. Recording playback is available only through an authorized signed retrieval flow and every access must be audited. Never use or expose a raw storage URL.
