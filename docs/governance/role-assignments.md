# Codestra governance role assignments

Effective 2026-07-28, Codestra SRL assigns the following governance roles to
Ralph Appolon (`appolon1908-hue`) under resolution
`CODESTRA-GOV-RES-2026-001`:

| Role | Responsibility |
| --- | --- |
| Organization Owner | Maintains the governance structure and approves future role changes. |
| Release Owner | Authorizes exact release sources, accepts release-process deviations, and approves progression into release gates. |
| Security Owner | Accepts or rejects security decisions, vulnerability dispositions, VEX records, and security deviations. |
| Compliance Owner | Approves privacy, consent, DNC, retention, recording, destination, email, and SMS policies. |
| Operations Owner | Approves operating windows, monitoring, incident response, support ownership, and controlled observations. |
| Rollback Approver | Authorizes rollback, backup restoration, emergency shutdown, and restoration of fail-closed state. |

The Release Owner and Security Owner overlap is explicitly authorized by the
bootstrap resolution. Independent exact-head review by a separate approved
reviewer remains required, and role-specific decisions must be recorded
separately.

Normal operating hours are 09:00–17:00 in `America/New_York`.
