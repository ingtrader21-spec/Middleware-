# OpenBao -> Prometheus (2026-09-16)

- Endpoint `GET /v1/sys/metrics` with `params: {format: [prometheus]}` on the private observability listener (`codestra-bao-<env>-01:8200`), mTLS (`ca_file`, `cert_file`, `key_file` from `/run/secrets`), bearer from `credentials_file: /run/secrets/openbao-prometheus-token`.
- Credential: a short-lived token minted by the `prometheus-openbao` role (300 s, renewable), bound to `workload-prometheus-openbao-<env>` which grants `sys/metrics` read only (`openbao/policies/<env>/prometheus-openbao.hcl`: `path "sys/metrics" { read }`, `path "sys/*" { deny }`). Nothing long-lived in `prometheus.yml`; `validate.py` fails closed on any inline `bearer_token`/`password`/`client_secret`/`credentials`.
- Prometheus job `codestra-openbao` (PR #70) stays `activation=pending` until the OpenBao runtime is certified; metric relabelling drops `token`, `secret`, `password`, `accessor`, `lease_id`, `request_id`, `path`, `mount_point`, `auth_display_name`, `id`.
- Telemetry contract (`config/telemetry/telemetry.v1.json`): `unauthenticatedMetricsAccess=false`, `secretLabelsAllowed=false`, required signals initialized/sealed/active/standby/leader/raft peers/request rate and latency/auth failures/token and lease counts/revocation/storage latency/memory/cpu/filesystem/restarts.
- Health: Blackbox module `https_openbao_health` (GET `/v1/sys/health`, 200/429 healthy, body must say `initialized:true, sealed:false`, never unseals) — authoritative in Codestra-Blackbox-Exporter `config/blackbox.yml`, mirrored in Prometheus, targets in Prometheus `blackbox/targets-production.json` (pending) and OpenBao `monitoring/blackbox/openbao-health-targets.json`.
- Alerts: OpenBao repo `monitoring/alerts/openbao-alerts.yml` (24 rules) and Prometheus `rules/openbao-alerts.yml` (10 governed rules with owner/service/environment/runbook) — availability, sealed, no leader, standby-only, health-probe failure/latency, audit device failure/silence, auth-failure surge, policy-denial rate, lease-revocation surge, scrape-token expiry.
- `promtool 3.14.0 check rules`: SUCCESS for every rule file; `check config --syntax-only`: SUCCESS.
