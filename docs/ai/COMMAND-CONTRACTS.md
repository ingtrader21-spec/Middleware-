# Command contracts

Supported contracts are `ai.chat.v1`, `ai.coding.v1`, `ai.crm.v1`, `ai.voice.v1`, and `ai.embeddings.v1`. All use schema version `1.0`, strict unknown-field rejection, tenant and actor binding, idempotency, deadlines, logical model profiles, bounded resources, data classification, callback policy, and approval policy. Provider URLs, credentials, tokens, passwords, and shell fields are rejected.
